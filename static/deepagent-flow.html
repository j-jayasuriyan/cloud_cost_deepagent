Persistence — two SQLite databases, both in the project root
chat_history.db
Stores session metadata and message text for the history panel sidebar. Managed by chat_db.py using the standard sqlite3 module (synchronous). Tables: sessions, messages. Created automatically on first import of chat_db.
langgraph.db
Stores the agent's full conversation checkpoints — every message and tool call/result pair per thread_id. Managed by AsyncSqliteSaver (LangGraph) via aiosqlite. WAL mode enabled at startup so delete endpoints can open short-lived connections alongside the long-lived saver. Tables: checkpoints, checkpoint_blobs, checkpoint_writes.
